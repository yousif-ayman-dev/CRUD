# CRUD

Simple CRUD website built with HTML, CSS, and JavaScript.

## Description

This project demonstrates a basic CRUD interface for creating, reading, updating, and deleting items in the browser.

## Usage

1. Open `index.html` in your browser.
2. Use the form to add new entries.
3. Edit or delete entries directly from the list.

## Files

- `index.html` - main page structure
- `style.css` - page styles
- `script.js` - CRUD behavior and interactions
